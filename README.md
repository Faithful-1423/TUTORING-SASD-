# SASD Tutoring Website

A small, student-built front-end prototype for a tutoring website inspired by the Souderton Area School District (SASD). It presents tutoring subjects and classes, with draft About Us and Contact sections and a separate account login/sign-up screen.

## What's in the site

- **Home page** (`front-end/index.html`): introductory section, offered classes grouped by subject, About Us and Contact sections, and school-related resource links.
- **Account page** (`front-end/Login.html`): login and sign-up interface mockup.
- **Styling and behavior** (`front-end/Apps.css` and the JavaScript files in `front-end/`): page design, class-list rendering, and login/sign-up form transitions.
- **Images** (`images/`): SASD logo and light/dark browser icons.

## Run locally

Open `front-end/index.html` in a browser to view the home page. Open `front-end/Login.html` to view the account page. The project is plain HTML, CSS, and JavaScript; it does not currently have a build step or package dependencies.

## Current status

This is a work in progress, not a production tutoring or account service. The class list is sample front-end content, the About Us and Contact sections still contain placeholder text, and the login/sign-up forms do not connect to a backend. Some navigation links are currently tied to a developer's local file paths and may need updating to work in other environments.
